# Tiny chess
Deterministic Python chess engine with negamax, alpha-beta, transpositions,
MVV-LVA, killers, quiescence, material and piece-square evaluation.
Run: `MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 -P -s main.py`
Standard library only. MIT licensed.
